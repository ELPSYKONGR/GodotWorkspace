# 镜头跟随受世界边界限制

日期：2026-11-16。用户反馈跟随不生效；依据实际`outputs/control`快照定位，未以长场景演示代替用户场景。

## 根因与处理

用户场景的世界范围是720×1280，等于画幅；镜头为`follow_y`，`limit_world=true`，跟随目标自动选择首个动态物体。根球和后代均已识别，但合法镜头Y范围只有0，目标落出画面时镜头仍被限制在0。先前状态仅显示“跟随”，未说明受限原因，造成设置失效的误解。

保留边界限制的原有语义与镜头轨迹算法，不静默扩大世界或移动地板。现在：

- 场景面板在“纵向跟随＋世界限制开启＋高度不超过1280”时显示具体原因及“允许越界跟随”。
- 该按钮关闭世界限制并通过已有命令应用当前世界/镜头设置。世界范围未改时保留物理世界、运行/暂停状态和当前时间；若同时修改了世界范围，仍遵守既有物理重置规则。
- 运行状态显示“镜头受限”，悬停可看具体原因。`state.camera.blocked_reason`新增`world_too_short`、`world_edge`或空字符串，供AI区分世界太短/到达边界；这是附加诊断字段。
- 原有世界边界限制仍有效。希望镜头仅在有限长世界移动时，增加世界高度并保留限制。
