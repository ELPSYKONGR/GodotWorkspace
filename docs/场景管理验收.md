# 场景文件与四类型整合（2026-11-14）

## 操作

同一工作台顶部提供“新建场景／打开场景／保存场景／另存为”。新建窗口有二维、正交三维、透视三维、玻璃演示四种类型，默认载入示例；取消“包含示例物体”即可从空场景开始。创建后使用同一套物体、机制、渲染、音效、回放和生产功能，玻璃仍是二维场景类型。

首次保存或另存为会打开文件窗口，默认工程`scenes/`目录；已打开/保存的文件再次保存时使用当前路径。支持中文文件名和其它绝对目录。示例配置受保护，不能用保存操作覆盖四个内置模板。文件写入采用临时文件、刷新后替换，失败时保留原文件及当前编辑。用户场景目录默认不纳入源码Git。

顶部显示当前文件、类型、完整路径与未保存星号，窗口标题同步更新。保存基线比较忽略命令修订号，所以撤销回已保存内容会清除星号。界面新建/打开时，如果有未保存的编辑，会询问保存、不保存或取消；取消文件选择或保存失败不会继续切换。属性输入需要先点击该页“应用”才进入初始场景数据。

场景保存初始布局和设置，运动轨迹单独使用Take保存。载入不同物理场景的Take时，其场景成为未保存副本，避免沿用之前的文件路径覆盖另一场景。旧AI命令`scene.preset`保留固定场景标识；新`scene.new`生成独立标识，`name`为2d/3d/perspective/glass，`blank`可选。界面保护由场景栏负责，直接AI命令仍按明确指令执行。
