## 增量验收：子球继续分裂

机制页新增`params.children_can_split`开关，旧场景未填时默认为`true`。复验使用原生2D/3D接触，没有构造假的碰撞事件；证据为`outputs/split_inheritance_baseline.json`及`outputs/split_inheritance_validation.json`。

| 场景 | 实测结果 |
|---|---|
| 默认二维预设8.004秒 | 46次分裂，48颗活跃球，最高第8代，后代机制保留，生命周期账目成立 |
| 默认场景的未执行原因 | `capacity_limit` 2026次、`birth_space_blocked` 47次、`newborn_guard` 77次；首次容量拒绝在成片4.292秒、模拟2.417秒 |
| 缺字段 / 显式开启的小夹具 | 二维到第4代，三维到第3代，各7次分裂、8颗球；仍受容量约束 |
| 显式关闭的小夹具 | 两个维度均只分裂1次、产生2颗第一代子球，后续记录`children_split_disabled` |
| 开启但容量设2 | 两个维度均保持2颗球，拒绝原因为容量不足，开关不会取消上限 |
| 关闭并挂载另一条接触移除规则 | 子球仍执行其继承的移除规则，最终0活跃、3退役，账目成立 |

新增机制验证共15项全部通过，包括拒绝字符串/数字/null而接受布尔值。UI共21项通过，覆盖开关默认、关闭/重建/再次开启、其它参数及源文档保持、上限提示与中文历史原因。13项命令、8项会话检查通过。此次未改生产链路，未重新生成成片；下面保留首版已完成的媒体验收结果。

接触事件以Godot原生接触/区域重叠为准。表现锚点可能取形状表面估算，`position_source`明确记录来源；未获得的求解器法线和冲量保留null。二维例子中偏心落球x=207.8101，地面中心x=360，效果锚点实际为[207.8101,1129]。

## 本次修正及边界

修正Windows PowerShell 5的原子替换空路径和进程空退出码问题；读取任务状态时保留上一次完整状态，避免Windows文件替换的瞬时空读误报。关闭音效、回放暂停会立即停止已有声音。成功加载场景或寻帧会清除旧运行错误。锁定物体在预览和数据编辑中均不可移动。

这是可实际制作样片的首版工作台：2D圆/矩形、3D球/盒、静态边界和sensor；正交三维提供2.5D观感。机制首版支持接触分裂、接触消失、分裂顿帧与逐代颜色；力场、软体、绳索、任意网格和复杂约束尚未实现。

粒子、冲击圈、闪光和拖尾按时间直接计算；三维特效目前投影到屏幕空间，不是原生3D GPU粒子系统。轨迹是完整JSON，最多60秒、60000采样帧；最多256动态＋256静态/区域对象。累计生命周期定义不计入逐帧512体上限。高频率、大物体数量会增加内存与文件体积；尚未分块或压缩，不承诺跨机器重新求解逐帧一致。

生产当前为一个活动任务，支持30/60fps、720×1280或1080×1920；只读已有轨迹，不重复物理解算。Compatibility预览使用OpenGL，Forward+生产使用Vulkan，本轮没有实现DX11后端切换。AI通过命令文件及代码修改控制工程，没有内置付费模型、聊天服务或自动上传平台。
