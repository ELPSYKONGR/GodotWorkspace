# 二维荧光材质（2026-11-14）

## 使用

关闭需要保留的旧工作台前，先保存场景及所需Take。双击任务根“荧光演示.cmd”或本工程`neon.cmd`；也可在顶部“新建场景”选择“荧光演示”。已有工作台时根启动器保留单实例保护，不覆盖活动窗口。

普通二维场景：打开“渲染”页，勾选“启用二维荧光材质”，调整光晕范围、光晕强度、小球高光大小、小球高光强度，点击“应用二维荧光材质”。颜色沿用物体自身颜色，保存场景时这些参数一并保存。修改只影响表现，保持真实刚体、位置、速度和已有Take；可随时关闭，恢复原来的纯色绘制。三维仍使用原有材质和光照设置。

## 实现与范围

参考本地视频7706089587995271651的青蓝/粉色边框、光晕和球面亮点，使用两个MultiMeshInstance2D批次分别绘制圆球和矩形/线段物体。球面法线、高光、边缘亮色和有限范围软光晕在同一着色器中解析计算，无逐球灯光或逐球绘制节点；原生刚体继续负责碰撞。

该路径可运行于现有Compatibility后端，不依赖全屏HDR辉光或新增资源包。这里的光晕是屏幕表现，不会把附近物体真实照亮，也不是实时三维反射/折射。玻璃面继续使用自己的材质；开启后普通圆球可获得荧光高光，玻璃面不被荧光边框材质替换。圆弧原语保持原来的显示路径。

`presentation.render.neon`字段：enabled布尔值（旧场景缺省false）；glow_width为1～64逻辑像素，glow_strength为0～2，highlight_size为0～1，highlight_strength为0～3。预览、回放和独立生产共用同一套着色器与参数。

荧光演示包含32颗青蓝球、96颗粉球及20个原生静态边框/平台，120Hz求解。它是视觉与真实碰撞示例，没有复刻原片的万球数量、楼层增长/破裂与计数玩法，也没有扩大256真实动态体上限。新建窗口原四类型保留，荧光为第五个选项。

为支持大量初始球，World2D把原来每次绘制都扫描初始物体的颜色查找改成缓存；表现修改时更新缓存，后代仍继承根物体颜色和代际变浅规则。

## 验证与证据

- 17阶段完整回归通过，耗时49.387秒，含新增荧光专项、分裂、玻璃、场景管理、界面、真实录制/回放、独立带声音生产及WAV冻结生产。
- 荧光专项14项通过：非法参数拒绝、实际面板提交、共享材质参数更新、物理不重置、旧Take不失效、两批实例数量、回放/回退位置及保存重开设置。
- 128球真实GPU窗口运行18秒，排除首秒：平均60.00FPS，P95 17.60ms，P99 18.58ms，最长21.03ms，无超过33.34ms帧。仍有帧间隔波动，不称为每帧严格16.67ms保证。计时没有使用fixed-fps；逻辑验证的固定步长不作为性能证据。
- 8秒720×1280、60fps带声音H.264/AAC样片完成，480帧及完整音视频检查通过；抽帧确认边框、光晕和球面高光进入成片。声音使用已有bell合成音。
