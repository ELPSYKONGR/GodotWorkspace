## 2. 现有能力和边界

状态约定：**已实现**指面板可操作；**仅JSON**指代码已经读取，可用配置或AI命令设置；**待新增**指需要实现代码和验证，单加字段不会生效。

核对依据为 `src/mechanisms/contact_rules.gd`、`src/physics/world_2d.gd` / `world_3d.gd`、`src/presentation/` 及 `src/ui/` 的当前实现，不把Godot自身具备但工程尚未接入的能力列为已实现。

当前机制只有球体碰撞分裂、碰撞删除和分裂顿帧。分裂是退役原球、生成新球，删除是不留碎片地移除物体；二者都不是原形状真实碎裂。默认分裂保持子球尺寸，不能称为面积或体积守恒破坏。`size_policy` 和额外喷射速度可以在JSON设置，但仍是球体替换机制。

当前2D物理使用逻辑像素，Y向下，速度为逻辑px/s；3D配置使用米，Y向上，速度为m/s。2D不能直接使用3D的速度、尺寸或能量阈值。三维场景中的现有粒子也是投影后的屏幕效果，速度为屏幕px/s，不参与世界碰撞。

“2.5D”目前可用真实三维场景加正交相机制作。二维物理解算驱动三维显示、自动约束全部物体在某平面的专用模式，均尚未实现。

## 3. 触发、计次和耐久

| 设置组 | 现状 | 建议新增选项与试制值 |
|---|---|---|
| 触发对象 | 已实现碰撞层/掩码、球与边界标签；仅JSON可设其他标签/规则优先级 | 每物体“可破坏”、接受的攻击者标签、计次对象；默认只有攻击球能损伤玻璃层 |
| 一击定义 | 已有接触episode去重和新生保护；未有耐久扣减 | 按“物体对＋接触episode”计一次；持续贴靠不连续扣数，分离再碰才是新的一击 |
| 耐久 | 待新增 | `initial_hits=8`、`damage_per_hit=1`、剩余值下限0；归零只提交一次破坏，支持预设8/16/32逐层递进 |
| 损伤反馈 | 待新增 | 裂纹在剩余75%/50%/25%分三档；计数绑定实际损伤事件，增加“-1”反馈和当前目标高亮 |
| 强度门槛 | 真实法线/冲量未采集；开启现有最低冲击要求会拒绝并报原因 | 选择“真实接触即计次”“相对速度代理”“真实求解器冲量”；首版默认第一项，其余不可用时明确显示 |
| 次序与节奏 | 已有子球新生保护、分裂顿帧；未有通用破坏顿帧 | 层顺序、允许同时损伤数、阶段完成条件；首版单目标，破坏顿帧0.04秒，需扩展到破坏事件 |

当前事件明确记录 `normal=null`、`impulse=null`，不能用它们做已经有效的冲量阈值。速度代理需要新增碰撞前速度采样；只测相对速度模时，就叫“相对速度”，不叫撞击力。若估算法向，还必须记录法向来自真实接触还是几何估计。用碰撞后的反弹速度代替碰撞前速度会误判。

未来接入引擎真实接触数据后，才开放真实冲量阈值；拿不到时拒绝该条件，不填0冒充测量。传感器重叠也不等于物理撞击。二维像素体系不应直接标注牛顿或焦耳。

## 4. 物理碎片与视觉碎屑分开

| 设置组 | 现状 | 首版建议 |
|---|---|---|
| 真实碎裂 | 待新增 | 先做矩形/盒体预切分；2D默认8块、3D默认8块，保留破坏前轮廓，碎块具备真实碰撞体 |
| 分块方式 | 当前只支持圆/矩形/线段或球/盒 | 首版规则切分；不规则多边形、Voronoi、球体断面和任意网格破坏另做形状与资产管线 |
| 质量与运动 | 现分裂会平分质量、附加喷射速度 | 碎块质量总和等于原物体，按面积/体积分配；继承平动及旋转产生的速度，处理重心和惯量；默认额外爆散为0 |
| 碎片出生 | 已有球体分裂的容量/空间拒绝 | 新碎裂同样先验证全批容量与非重叠位置；成功才退役原物体，失败保持完整并给原因 |
| 物理预算 | 已实现动态上限，最高256 | 初始试制总动态上限64；单次最多8块，碎片不继续破坏；寿命3秒、离屏回收、休眠阈值均需新增 |
| 视觉碎屑 | 已有屏幕圆形粒子；不是不规则碎片 | 新增同色多边形碎屑24个，寿命0.6秒、大小2～8px；默认不碰撞，不占真实刚体预算 |
| 粉尘与裂纹 | 待新增 | 各自独立开关；粉尘默认关闭，裂纹保留在受损物体上，不用全屏爆光遮住结果 |

预切分不等于先让内部碎块自由碰撞：破坏前应由完整物体承载碰撞，破坏后才启用碎块。可额外提供“仅视觉破坏”模式，明确标为外观演出；不得让视觉碎屑数量悄悄增加物理解算成本。

## 7. 复现与首版验收

现有JSON虽有 `world.seed`，当前实现并未用它驱动物理随机；特效使用已记录事件种子。可以复用同一Take恢复生命周期/姿态并重建特效，不能承诺同种子重跑原生物理或跨硬件逐位一致。

新增破坏应分别保存场景种子、碎裂种子、效果种子及声音选择；碎块拓扑/ID、出生状态、耐久变更和破坏时刻写入Take。离线生产读取记录，不重新求解破坏。修改耐久、触发或碎片规格需重新录制；纯外观参数尽量复用轨迹。

首版推荐：少量矩形/盒体预切分＋同色视觉碎屑＋8次耐久＋三档裂纹＋固定镜头。先通过以下检查，再做环扇区和不规则碎裂：

- 同一接触不重复扣数，持续贴靠不扣到归零；剩余0时只破坏一次。
- 原物体与真实碎片不同时保留，质量合计正确，出生不重叠，容量不足保持原物体。
- 倒放/寻帧后计数、裂纹、碎片和声音事件相同；顿帧不造成重复提交。
- 2D和3D分别用各自单位与预算验收；视觉碎屑关闭后不改变物理结果。
- 导出的干净画面无调试叠加，实际非静音，音画对齐；先看低粒子版本也能否清楚读懂目标和破坏结果。
