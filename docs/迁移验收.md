## 4. 问题与限制

- 首次外层执行重定向导致工具会话提前退出，未采纳复制来的旧报告作为通过；拆开编排后直接执行完整脚本成功，正式报告记录的是这次新执行。
- 构建预检时Git换行警告经PowerShell stderr被当成错误；打包器已捕获Git查询stderr，重新构建并校验成功。
- 打包审查发现旧MANIFEST会被再次纳入自哈希、校验路径可越出包目录，均已修正并有回归检查。
- 一次许可查询误用Godot未知参数，启动了临时后台实例并触发发布文件竞争；已停止这些实例，改为读取官方许可文本，后续只在副本运行。包使用此前明确保存的revision33初始场景，不把临时发布状态当作用户布局。
- 项目当前具备模块边界但未严格四层解耦；真实碎裂/耐久等仍待实现。可迁移不等于这些功能已完成。
- Windows/显卡驱动/系统字体仍由目标电脑提供；Linux/macOS和另一台硬件未实际验收。远程4080机器尚未部署。

新电脑建议先运行包完整性检查，再启动短场景并生产一段短片；需要重新完整验收时在独立副本运行统一套件。
