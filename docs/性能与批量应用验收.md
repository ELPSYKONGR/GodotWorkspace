# 性能、最低碰撞速度与统一应用（2026-11-14）

## 使用

机制页新增“分裂最低碰撞速度（0关闭）”。二维单位为px/s，三维为m/s。例如二维设100时，接触前相对速度低于100的碰撞不触发分裂；设0保留旧行为。撞静止墙面时，相对速度就是球速；两球相向运动时按二者速度差计算。该值使用前一物理步的线速度近似，不是碰撞冲量、法向速度或包含自转的接触点速度。一次接触片段固定使用其进入时的采样值，不因接触后加速反复分裂。低速拒绝会显示在调试与事件记录中。

顶部“应用更改并运行”收集各页已修改设置，统一校验成功后从初始布局重新运行。覆盖物体、机制、重力/频率/容量、文字/渲染/荧光、声音、特效和输出参数；支持先后编辑多个物体再一起应用。未修改的表单组不提交，不会因新建演示的机制页默认选项而自动创建分裂规则。整批修改只增加一次撤销记录；任一设置无效则不修改文档、不重置运行状态。

即时特效开关仍可直接使用；它重建面板时会保留其它页已输入的草稿。只有输入数值不代表已经修改保存文件：先统一应用，再点击“保存场景”。轨迹文件路径、生产任务名以及录制/导出按钮是独立操作，不会因为统一应用而自动录制或导出。

“分裂顿帧”会刻意冻结物理，不能单凭运动短暂停住判断FPS下降。需要连续运动时可在机制页关闭此效果，统一应用并运行。本轮未擅自覆盖用户场景或关闭其顿帧选择。

## 性能改动

- 回放不再每帧复制整份初始物体并重设所有材质。创建回放世界和实际表现参数修改时仍更新材质；新出现的物体按当前场景设置创建。
- 回放声音只二分查找当前时间段的事件，不再每帧遍历整个Take事件列表。导入Take要求事件时间有序，拒绝乱序数据。
- 控制桥仅在场景修订变化时写scene.current.json；状态文件继续更新，保留AI命令和原子发布。
- 编辑/暂停状态在时间和事件不变时不重复构建拖影、粒子与玻璃表现；二维编辑世界不再随每个物理tick重复提交同一批显示实例。
- 三维调试显示状态相同时不再重复重设材质。
