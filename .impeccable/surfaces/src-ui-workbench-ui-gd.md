# 工作台重设计：设置合理性与布局

范围：Godot 原生工作台。模式：Operate，以完成视频制作任务为准。用户已确认的产品事实见根目录 PRODUCT.md；本次视觉细节由实现方按“简洁、美观、好用”执行。

## 产品判断

旧界面的问题不是功能不足，而是把开发调试结构直接呈现给创作者。九个同级标签、三行顶部操作、整段说明和常驻缩略图使预览高度不足；物体列表又占着属性页，选中后需要长距离滚动。

| 原设置或入口 | 判断 | 本次处理 |
| --- | --- | --- |
| 初始物体列表、形状和位置 | 高频，属于主要工作对象 | 列表固定左侧；几何与布置默认展开 |
| 物理模式、速度、质量、弹性、摩擦 | 必要，但不是每次都修改 | 独立折叠组；保留真实校验和重置语义 |
| 全部二维和三维材质并列 | 对当前场景无关的字段制造干扰 | 按维度显示；隐藏不适用项，不删除已有数据 |
| 独立材质和特效 | 必要，必须明确作用范围 | 当前物体内分组；选择“跟随全局”时隐藏独立参数 |
| 碰撞层、掩码、标签、CCD | 低频技术选项 | “高级碰撞”默认收起；内部值保留 |
| 重力和物理频率放在分裂页 | 分类错误，不属于分裂本身 | 移入“场景 → 世界物理”；容量仍在机制保护项 |
| 编辑布置与重置两个入口 | 结果重叠 | 只保留“返回布置”，旧 AI 命令兼容 |
| 开始录制和停止录制分开、多页重复 | 同一状态操作重复 | 底部单按钮随录制状态切换 |
| 新建、打开、另存为全部常驻 | 低频，占用顶部 | 收进“文件”；保存直接可达 |
| 每种物体分别一个添加按钮 | 高频入口、低频类型选择 | 一个“添加物体”菜单；二维绘制单独可达 |
| 排列、复制、删除常驻 | 有用但无需抢占属性空间 | 左侧“物体操作”菜单；Delete 保留 |
| 缩略图常驻在预览下方 | 对长世界有价值，短场景浪费高度 | 移到左下“世界概览”，按需展开 |
| 逐帧、回放与单物理步混杂 | 两种时间语义容易误解 | 视频逐帧与录制放底部；单物理步进“更多” |
| 导出后端、任务名称 | 低频，不该抢在尺寸/帧率前面 | 收入“高级导出”；显示计算后的时长 |
| 无轨迹、已过期、导出中仍可反复点击 | 容易失败 | 显示原因；根据实际状态禁用不可执行操作 |
| 大段机制/工程说明 | 有帮助，但干扰日常使用 | 删除常驻段落，关键限制保留在提示和说明文档 |

## 布局与交互

- 顶部：文件与场景身份、保存、撤销/重做、应用并运行、导出视频。
- 左侧：物体列表、添加/绘制、物体操作、六个设置入口、折叠世界概览。
- 中央：干净竖屏实时预览、返回布置和一行运行状态。
- 右侧：当前物体属性，或选中的全局设置；不再横排九个标签。
- 底部：运行/暂停、录制/停止录制、逐帧、时间轴、时长和更多菜单。
- 点击画面或物体列表可回到物体属性。切页、换物体时保留草稿；批量应用沿用一个事务。
- 常规数值框固定 88px，两列自动换行；文字、路径、颜色使用所需宽度。
- 窗口缩小时保持字号和输入宽度，不把整套界面缩成小字。支持的最小窗口仍为 1100×720。

## Direction contract

THESIS：以画面为中心，让物体、当前属性、全局设置各有位置；替换旧九标签与说明堆叠。

OWN-WORLD：矿物绿中性色面板、薄荷色主操作、系统中文字体、紧凑原生表单；色彩表达选中和状态，不为场景加装饰。

STORY：先看到场景及其物体，选中即调属性；运行验证，录制、回放，再导出。AI 和用户仍共享真实命令路径。

FIRST VIEWPORT：1440×900 下左侧约220px、右侧约382px，中间独享剩余空间；主导出在右上，录制及时间轴在底部。特征交互是“点画面即定位物体属性”，不是跳转到另一套编辑器。

FORM：方向三，克制的矿物绿工作空间；seed:2026fca24e6471ba。外部方向服务本次不可用，没有取得外部对照设计板；该随机记录不代表用户审美偏好或外部设计背书。方向与布局按本轮直接实现请求选择，未宣称获得额外方案审批。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 验证边界

以原生 GPU 截图验证 1440×900、1100×720、1920×1080 和各设置页。专项检查覆盖草稿、维度过滤、材质继承、录制状态、导出状态、键盘与点击选择。运行回归验证已有机制和生产链；不把网站检测器结果当作 GDScript 的质量证明。

Taste 的网站章节、照片、营销动画规则不适用于该原生工具；只采用一致边距、真实产品画面、简短文案和完整状态原则。Impeccable 使用 Operate 模式的原生习惯、密度和渐进披露原则。
