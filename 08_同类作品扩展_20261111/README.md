# 同类型作品扩展与原视频归档

采集日期：2026-11-11。该目录在前一轮11条案例基础上，新增27条B站与10条抖音同类型公开作品；排除1条黑屏互动弹幕测试后，形成47条主样本（B站32、抖音15）。

## 目录

- `bilibili/cases_additional.json`：新增27条逐条记录、指标、机制归类、设计假设与证据路径。
- `bilibili/notes.md`：27条逐条分析和跨样本设计规律。
- `bilibili/cases_33.json`、`cases_33.csv`：前一轮6条与新增27条合并清单。
- `bilibili/videos/`：27个公开播放流MP4，采用B站公开 `qn=16`（通常360p）。
- `bilibili/frames/`：每条下载视频的中段抽帧。
- `bilibili/*_api.json`：B站公开详情接口原始响应。
- `bilibili/*_playurl.json`：公开播放接口原始响应。
- `bilibili/download_manifest.json`：文件大小、SHA-256、来源与完整性清单。
- `bilibili/contact_sheet_27.jpg`：27条抽帧总览。
- `douyin/cases_additional.json`、`douyin/notes.md`：10条抖音公开详情、页面指标、截图和下载状态。
- `douyin/抖音扩展案例截图对照.png`：抖音扩展截图索引。
- `cases_merged.json`、`cases_merged.csv`：47条统一字段目录。
- `00_47条同类作品分析.md`：逐条索引、机制归类、爽感设计分析和对现有程序的改进建议。
- `案例抽帧总览.png`：36张已保存抽帧的统一索引。
- `original_videos/`：单独原视频研究副本目录；当前40个可播放MP4。
- `tools/download_bilibili_public.py`：B站公开下载和完整性清单脚本；仅调用公开接口。

## 下载口径与权利边界

本轮27/27条新增B站作品均通过无需登录的公开播放接口下载成功；B站原始下载目录另含前一轮作品，共33条公开播放流。保存的是平台返回的公开播放流，通常为360p，**不等于创作者原始母版**。新增抖音中7条正常下载，另有原参考作品可复用的1条MP4；3条扩展抖音媒体下载失败，仅保留页面证据。下载成功只说明研究归档可用，不授予转载、改编或商业发布权；对外发布前仍需确认版权、平台条款和必要授权。

没有使用账号登录、cookies、验证码、付费权限或绕过限制。若后续重新执行，接口可能因平台策略变化失败；脚本会保留失败记录，不会将失败伪装成下载成功。
