# 同类作品原视频研究副本

截至 2026-11-11，本目录保存了 33 条 B 站同类型几何/小球物理动画作品的公开播放副本，均通过 B 站官方 `view` 和 `playurl` 接口取得，`rights.download=1`。视频与音频采用 DASH 流后由本地 ffmpeg 合并为 MP4；多数选择不高于720p，实际可用流通常为640p或480p。总大小约68.7MB。

## 目录

- `bilibili/<BVID>/<BVID>.mp4`：单条研究副本。
- `bilibili/<BVID>/manifest.json`：标题、上传账号、抓取时播放/点赞、权限字段、选用流、字节数和来源API。
- `bilibili/download_manifest.json`：33条批量汇总。

## 使用边界

这些文件用于本地分析、抽帧和技术研究，上传账号是平台显示的投稿账号，不等于本地已独立核验完整权利链。不得因为 `rights.download=1` 就把它当作取得商业转载、改编或再发布授权；发布衍生作品前仍需获得权利人许可并遵守平台规则。签名媒体URL不保存于报告，失败条目会留在清单中。
